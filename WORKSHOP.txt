Native iPhone workshop app (working name Adder; final name undecided)

Implementation
- SwiftUI native app, exact ZeticMLange SDK 1.11.0 via Swift Package Manager.
- Liquid zetic/LFM2.5-1.2B-Instruct version 1 interprets action fields.
- Liquid zetic/LFM2.5-VL-450M version 1 understands photos at Preview.
- Vision inference is implemented but awaits physical-device verification.
- Zetic OpenAI/whisper-tiny-encoder and whisper-tiny-decoder version 1 transcribe locally.
- Whisper uses bundled vocabulary and 80-bin filterbank; Accelerate is linked.
- A development PAT is supplied through a hidden Mac dialog and an ignored
  private build configuration. No token entry is needed on the phone.
- Review and Save are separate; no Contacts/Calendar/Reminders writes before Save.
- Australian mobile normalization, explicit spelled email precedence, strict dates.
- Contact notes include meeting context plus actual capture timestamp/timezone.
- Event creation can include a separate preparation task in Apple Reminders.
- A reminder is due at the same local clock time, N days earlier; preview shows it.
- Event duration is required and visibly chosen before saving.
- Recent saved people and history are held locally for follow-up context.

Device setup
1. Connect/unlock the iPhone and enable Settings > Privacy & Security > Developer Mode.
   Complete the restart and confirm Developer Mode after reboot.
2. Open Adder.xcodeproj. Sign into Xcode Settings > Accounts.
3. Select Adder target > Signing & Capabilities > your Personal Team.
4. Build/run on the physical phone. Simulator does not verify Melange execution.
5. Create a development Melange PAT on your Mac at
   https://melange.zetic.ai/settings?tab=pat. Run
   python3 scripts/configure-local-key.py and paste into the hidden Mac dialog.
6. Rebuild/install. Local models load automatically while online; initial downloads take time.

Build command used when Xcode scheme destinations were unavailable
xcodebuild -project Adder.xcodeproj -target Adder -sdk iphoneos -configuration Debug CODE_SIGNING_ALLOWED=NO SYMROOT=build/Products build

Unsigned app is under build/Products/Debug-iphoneos/Adder.app.
An unsigned app cannot be installed on a regular iPhone; Apple signing is required.
